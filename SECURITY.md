# Security Policy

## Supported Versions

We provide security patches and updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and privacy of Tasker and its users seriously. If you discover a security vulnerability or potential threat in this repository:

1. **Do NOT disclose the issue publicly** in a GitHub issue, forum, or pull request.
2. Please report the issue by creating a private security advisory through [GitHub Security Advisories](https://github.com/yowRiss/tasker/security/advisories/new) or contacting the maintainers directly.
3. Include detailed instructions and steps to reproduce the vulnerability, including proof-of-concept code or payloads where applicable.
4. Allow sufficient time for the maintainers to review, triage, and patch the issue before any public disclosure.

We will acknowledge receipt of your report promptly and keep you informed of our progress throughout the remediation process.
